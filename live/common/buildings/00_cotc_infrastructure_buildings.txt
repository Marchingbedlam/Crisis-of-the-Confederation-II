# Goal is to make it noticeably more difficult to improve Hostile planets than atmospheric ones
# And more difficult to improve open space than Hostile planets
# Habitat Infrastructure is for building on corrosive, barren, etc.
# Orbital Infrastructure is for building on gas giants and open space. 
# Each level unlocks two levels of normal buildings but costs more
# Atmospheric planets get free buildings
# TODO: I created the requirement and the buildings for both orbital and hab
# TODO: Now just needs to be distributed across the other CotC buildings
# TODO: Also need to add the building slots and make sure that works correctly
