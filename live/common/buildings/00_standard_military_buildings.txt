# CotC Military Buildings
# Military Berths - Levy, General MaA Maintenance/Bonus
# Capital Shipyard - Poor Levy, Capital Ships
# 	- Require End Game Techs
# Officer Schools - Knight Effectiveness/Number, Global Advantage, Prowess
# 	- Start at Level 2 holdings
# HE Depot - Generic Damage, especially pikemen and archers
# 	- Corrosive world unique
# Patrols - Screen, skirmisher (etc) damage, control
# Regattas - Movement, Pursuit, Screen for lighter ships
# 	- Asteroid and open space restricted
# Weapon Test Grounds - Heavy ship damage, dread, opinion malus
# 	- Barren world restricted
# Marines Barracks - Siege, raids, hostile scheme bonuses
# 	- Atmospheric world restricted
# Gravity Forges - Toughness and reinforcement + tax
# 	- Gas and Frozen Giant restricted
