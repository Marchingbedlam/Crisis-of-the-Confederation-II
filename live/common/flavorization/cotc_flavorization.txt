# First Digit: Title Type
	# 1: Councillor
	# 2: Derived Aristocratic Title
	# 3: Ruler or Title
# Second Digit: Independence Status
	# 1: No Specific Status
	# 2: Vassal
	# 3: Contract-Specific
	# 4: Independent
# Third Digit: Title Rank
	# 0: No Specific Rank
	# 1: Barony
	# 2: County
	# 3: Duchy
	# 4: Kingdom
	# 5: Empire
	# 6: Hegemony
# Fourth Digit: Title Modifiers
	# 0: No Modifiers
	# 1: Culture Only
	# 2: Religion Only
	# 3: Government Only
	# 4: Culture + Religion
	# 5: Culture + Government
	# 6: Religion + Government
	# 7: All three
